# PvG bot

## Language: poppel

The bot speaks **poppel**: nynorsk in the absurd PoppelNytt voice (see https://www.poppel.news). Every bit of text a Discord user can see is poppel:

- command and option names and descriptions
- replies, embeds, buttons, menus and modals
- error messages shown to users
- text generated by a language model; its system prompt must require poppel

Code, comments, logs and docs (README, this file) stay in English, since they are read by developers, not Discord users.
